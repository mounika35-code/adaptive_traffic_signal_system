
# Adaptive Traffic Signal Simulation System

## Project Description
The Adaptive Traffic Signal Simulation System is a Python-based project that analyzes vehicle counts on four roads and adjusts green-light timings according to traffic demand.

## Objectives
- Analyze traffic density on four roads.
- Identify the busiest road.
- Calculate green-light timings based on vehicle counts.
- Simulate traffic signal rotation.
- Estimate waiting times and compare signal strategies.
- Generate simulation performance reports.

## Technologies Used
- Programming Language: Python
- Editor: Visual Studio Code
- Concepts: Functions, loops, conditional statements, dictionaries, and file handling

## Project Structure
- main.py – Main menu and program execution
- traffic_input.py – Accepts and validates vehicle counts
- traffic_analyzer.py – Analyzes traffic density
- signal_controller.py – Calculates signal timings
- simulation.py – Runs the signal simulation
- performance_analyzer.py – Analyzes performance and waiting times
- reports/ – Stores simulation reports

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run the command:

   py main.py

## Expected Output
The program allows users to enter vehicle counts, analyze traffic, run the signal simulation, and view a performance report.
